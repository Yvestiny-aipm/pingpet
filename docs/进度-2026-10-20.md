## 2. Cursor 终止信号

真实样本结论（本机 52 个 Cursor 父会话，排除 `subagents/`）：

- 45 个以 `turn_ended` 收尾；7 个是数月前的老格式会话
- 646 次 `success`，23 次 `error`，没有观察到 `status=aborted`
- 用户主动停止写成 `turn_ended/error` + `User aborted request` / `Canceled`
- 其它 error：`PING timed out`、`Connection failed repeatedly`、模型额度限制

当前规则：

| Cursor 末行 | 行为 |
| --- | --- |
| `turn_ended/success` | `done/completed`，气泡「Cursor 这一轮结束了，回去看看」 |
| `success` + 最后一句在提问/要授权 | `needs_attention`，气泡「Cursor 需要你处理一下」 |
| `turn_ended/aborted` | `failed/interrupted` |
| `error` + 明确用户中止文案 | `failed/interrupted`，气泡「输出被中断了」 |
| `error` + 超时/网络/额度/普通错误 | `failed/error`，气泡「出错停下了」+ 原始原因 |
| 没有 `turn_ended`，末行纯文本 assistant | 老格式低置信兜底 |
| 末行 user / assistant tool_use | `working`，只切思考态 |

`turn_ended/success` 只代表这一轮硬结束，不代表任务成功；文案不再写「任务完成」。完成提示音与 happy 姿态保留作为提醒。

## 3. Cursor 强制退出兜底

用于 Cursor 被强制退出 / 崩溃、来不及写 `turn_ended` 的情况。

触发条件：

- Cursor 监控开关打开；
- 会话环境是 `desktop`；
- 该会话最近状态仍是 `working`；
- Cursor 主进程从「运行中」变为「未运行」；
- 当前环境过滤通过。

防误报：

- 进程消失后等 2 秒，给 `turn_ended` 最后写入留时间；
- 2 秒内收到 `turn_ended`、Cursor 重启、会话超过活跃窗口，都取消兜底；
- 多个 Cursor 会话同时中断只补一条，detail 带「还有 N 个」；
- Cursor CLI 会话不套用这条兜底。

补出的提醒：

```text
Cursor 输出被中断了 ⛔
Cursor 进程已退出，未检测到 turn_ended
```

实现：

- `src/main/agent/cursorProcess.ts`：macOS `pgrep -x Cursor` 主进程探针，2 秒刷新
- `src/main/agent/monitor.ts`：进程退出状态机、2 秒宽限、多会话聚合
- `src/main/agent/monitor.test.ts`：8 个进程退出测试

## 4. Claude Code 终止信号

本机 4 个 Claude 会话样本中观察到：

- `stop_reason=tool_use` 80 次
- `stop_reason=end_turn` 14 次
- `stop_reason=stop_sequence` 3 次
- `isApiErrorMessage=true` 3 次
- `system/api_error` 1 次（retryAttempt=1 / maxRetries=10，属于自动重试）

当前规则：

| 信号 | 行为 |
| --- | --- |
| `isSidechain=true` | 忽略，不驱动主任务 |
| `tool_use` | `working` |
| `end_turn` / `stop_sequence` | `done/completed`，中性文案 |
| `end_turn` + 提问/授权 | `needs_attention` |
| `max_tokens` | `failed/error`，detail=输出被截断 |
| `isApiErrorMessage` / `error` | `failed/error` + 原始原因 |
| `system.api_error` 自动重试中 | `working`，不提前报错 |
| `system.api_error` 重试耗尽 | `failed/error` |

文本分类只用于判断「是否在等用户」，不再把「构建失败」等关键词升级成 failed。`uuid` 用作稳定事件 id。

相关文件：

- `src/main/agent/claude.ts`
- `src/main/config.ts`
- `src/main/agent/claude.test.ts`
