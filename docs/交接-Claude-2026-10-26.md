## 1. 项目是什么

PingPet 是一个 macOS 桌面透明置顶小桌宠：

- 本地监听 Codex / Claude Code / Cursor / Grok Bot 的会话文件；
- Agent 干活时只切 `thinking`，不打扰；
- 停下来时弹气泡，说明「结束了 / 需要你 / 出错 / 被中断」；
- 所有核心监控本地只读，不联网、不注入、不代理。

设置台是 Electron + React + TypeScript，桌宠窗口和设置窗共用一套 renderer。

## 5. 不可破坏的规则

这些是前几轮踩坑后冻结的，接手后不要放宽：

1. **`completed_signal` 不等于任务成功。**
   - Cursor `turn_ended/success`、Claude `end_turn`、Codex `task_complete` 都只是「这一轮结束」。
2. **子 Agent 不算主任务。**
   - Cursor 忽略 `subagents/`；Claude 必须过滤 `isSidechain=true`。
3. **文本关键词不能升级成高置信失败。**
   - 文本只用于 `needs_attention`；真正失败看结构化错误。
4. **工具 / item 失败不等于整轮失败。**
5. **普通中断不等于用户取消。**
   - Cursor 只有明确 `User aborted request` / `Canceled` 才算用户中止。
6. **终态必须先见过同会话的 working。**
   - 防止启动时补发历史完成。
7. **首轮 prime 不派发。**
8. **Cursor 终态只看最后一行。**
   - 不要改成全文件找 `turn_ended`，否则用户发下一条消息会重复提醒旧终态。
9. **Cursor 进程兜底只对 desktop / working 生效。**
   - CLI 会话没有单一桌面主进程，不要套用。
10. **不要为了让提醒更多而放宽证据。**
    - 宁可保留 `unknown`，不要猜。

## 8. 已知坑

### 8.1 Cursor

- `turn_ended` 没有行内时间戳，事件时间用文件 mtime。
- 用户中止是 `status=error` + 固定文案，不是 `status=aborted`。
- 不能用宽泛的 `includes('abort')`，否则 `Connection aborted` 会被误判为用户取消。
- 终态只认最后一行；改全文件扫描会重复提醒。
- 进程探针只认 macOS 主进程 `Cursor`，不认 Helper。

### 8.2 Claude

- `end_turn` 是每条 assistant 消息的结束，不等于任务成功。
- `isSidechain=true` 必须过滤，否则子 Agent 的结束会误报主任务。
- `system/api_error` 自动重试期间不能报错。
- 文本里的「失败 / 报错」不再升级成 `failed`；这是刻意保守。
- `uuid` 用作事件 id；如果改动 id 生成，注意去重。

### 8.3 主题

- 设置台 CSS 是静态打包的，宠窗也会加载；主题变量分 `--pp-*` 和 `--pet-*` 两套，不要混用。
- `body[data-theme]` 由 `SettingsApp` / `PetView` 设置；新增主题时两处都要处理。
- 深色开关要注意 CSS 优先级：`body[data-theme='dark'] .pp-switch` 会覆盖 `.pp-switch.is-on`，已有专门覆盖。

### 8.4 发版

- 不要改 `package.json` 的 `name`（会丢 userData 与钥匙串）。
- 不要手敲 Git tag。
- 版本号由 `package.json` 派生；发版必须用户明确要求。
