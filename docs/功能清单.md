## 一、产品定位

一只常驻 macOS 桌面的透明置顶像素桌宠。核心价值是替用户盯着本机的 AI 编码助手：
Agent 干活时安静陪伴，Agent 停下来时用气泡说清楚「为什么停」，把用户叫回来。

- 本地优先：核心监控只读本机会话文件，不注入、不代理、不改代码
- 无需账号、无遥测；联网功能全部可关闭或用户主动触发
- 轻量：菜单栏常驻，透明窗可拖拽，鼠标穿透不挡操作

## 三、Agent 监控

### 支持范围

| Agent | 终端 | VS Code | 桌面客户端 | 说明 |
| --- | --- | --- | --- | --- |
| Codex | ✅ | ✅ | ✅ | 读取 `~/.codex/sessions` |
| Claude Code | ✅ | ✅ | ✅ | 读取 `~/.claude/projects` |
| Cursor | ✅ | — | ✅ | 无官方 VS Code 插件；ACP 会话不写可读会话文件 |
| Grok Bot | — | — | ✅ | 官方只有桌面端 / iOS App；手机任务会同步到桌面端 |

每家可单独开关；开关开着但环境一个都不选 = 该家不监控。全部关掉 = 纯陪伴桌宠，不轮询。

### 监控机制

- 每 **1 秒**轮询一次本机会话文件；每家单次最多扫 12 个最近修改的文件
- 只读文件尾部 96KB；只处理最近 120 秒内的事件；mtime 超过 240 秒的文件直接跳过
- 目录递归深度 5；事件去重上限 500 条；活跃会话 120 秒过期
- 首轮扫描 prime：把历史事件标记为已见，避免启动后弹一堆旧提醒
- 终态提醒要求该会话近期出现过 working，避免「打开 App 就看到历史完成」
- 按环境过滤：只派发用户勾选的环境事件
- 事件四分类：`working` / `done` / `needs_attention` / `failed`
- 停止原因四分类：`completed` / `needs_input` / `error` / `interrupted`
- 保守分类：显式信号优先（如 Codex `turn_aborted`），自由文本只用高置信短语，宁可漏报不误报
- Codex 特殊语义：`task_complete` 只说「这一轮结束了」，不说「任务完成」，不播完成音
- 长任务保护：修复了 assistant 正文中途被误判为「结束」的问题

### Codex 实验性状态层（默认关）

- 影子观察：解析 `codex exec --json` 与本地 session JSONL，派生多维状态（lifecycle / cause / process / connection / session / turn / item / outputIntegrity / taskSemantics / retryability / confidence）
- 只写本地诊断 JSONL，不改变旧 Monitor 的 `onEvent` 语义
- 可选的「状态感知姿态」：工作中、部分失败、中性结束
- 可选的「部分失败提醒」气泡
- 独立 attention 提示音开关（设置里不展示）
- 诊断文件：`codex-shadow.jsonl`、`codex-candidate.jsonl`、`codex-legacy.jsonl`、attention sound 诊断

### 诊断与开发

- 设置台展示：最近检查时间、最近事件、活跃会话数
- 设置台实时刷新（Agent 事件会广播快照）
- 打包版不提供；开发版可对 4 家 × 4 种状态一键模拟，走真实处理链路

## 四、形象与皮肤

### 内置形象

- 3 只原创 SVG：团子（奶油猫）、布丁（小鸡）、墨墨（小墨团）
- 随 App 打包，永远可用；任何宠物丢失时回落到团子

### 单图导入

- 支持 PNG / WebP / SVG；选图后转 dataURL
- 自动去纯色背景：四角采样 + flood fill，在渲染进程本地完成，图片不上传
- 可关闭自动抠图；复杂背景自动跳过，不硬抠
- 存为用户皮肤包，并以文件名作为初始显示名

### 皮肤包导入

- 选择含 `manifest.json` 的文件夹，或多状态素材包
- 校验 manifest → 复制到临时目录 → 原子替换，失败回滚，不留半个包
- 素材状态：`idle` 必备，`happy` / `thinking` / `failed` / `attention` / `sleepy` 可缺省，按规则 fallback
- 支持重命名（1–30 字）、删除（仅已导入，官方不可删）
- 删除当前宠物时自动回落到团子

### PetDex 社区形象

- 兼容 PetDex / Codex 宠物格式：`pet.json` + 8 列 × 9 行 spritesheet（1536×1872，单帧 192×208）
- 9 行动作映射到 6 种状态：idle / jumping / review / waiting / failed 等
- 自动扫描 `~/.codex/pets`（PetDex CLI 安装的形象，只读纳入）
- 用户导入的 PetDex 包存到 `userData/pet-packs/petdex`
- 在线库：从 `https://petdex.dev/api/manifest` 拉全量列表（接口 `total` 实时读取；2026-10-19 实测 5,087 只），按 `zipUrl` 一键下载安装
- `deskpet://install?url=<https zip>&name=<显示名>` 协议：官网点「导入」直接唤起 App 安装
- 设置台的「形象库」页面已接入：联网提示、搜索、类型筛选、分页、一键安装、已安装状态

## 五、AI 总结（BYOK，默认关）

- 任务停下时读取该会话末尾 ≤6000 字符，用用户自己的模型生成一句 ≤45 字中文总结，拼在规则气泡第二行
- 模型服务：
  - Anthropic（默认 `claude-opus-4-8`）
  - OpenAI 兼容接口（OpenAI / DeepSeek / 月之暗面 / Ollama / LM Studio 等）
  - 硅基流动一键预设（Base URL 固定，默认 `deepseek-ai/DeepSeek-V3.1`）
- 12 秒超时、输出上限 300 tokens；429/5xx 自动退避 1.5 秒重试一次
- 任何失败（没 Key、超时、网络、空回复）都回落到规则文案，提醒永不缺席
- 「测试连接」用内置样例发一次真实请求，成功文案明确标注是「样例总结演示」
- 多 Agent 合并气泡不调用 AI，只有单条终态才生成总结
- 隐私：仅开启时联网；只发会话末尾文本；Key 用 macOS safeStorage 加密落盘，仅存本机

## 六、更新与版本

- 启动 20 秒后检查一次，之后每 24 小时检查一次；可关闭
- 只向 GitHub Releases 取一个版本号，不带用户标识
- 发现新版本：弹 12 秒气泡（每次版本只弹一次）+ 托盘常驻「下载新版本 vX」入口
- 只打开下载页，不做静默自动更新（当前 ad-hoc 签名无法通过 Squirrel 校验）
- 版本号统一由 `package.json` 派生，发版脚本自动打 tag

## 七、隐私与安全边界

| 维度 | 现状 |
| --- | --- |
| 网络 | 核心监控纯本地；联网仅：PetDex 形象库（主动触发）、AI 总结（显式开启）、更新检查（默认开，可关） |
| 代码 | 从不读取项目代码；只读 Agent 会话状态文件 |
| 系统权限 | 无辅助功能、无 AppleScript、无窗口聚焦、无屏幕录制 |
| 账号 | 无需注册，无遥测 |
| 凭据 | API Key 经 `safeStorage` 加密后落盘；旧明文 Key 启动时就地迁移 |
| IPC | 校验 sender URL；contextIsolation 开启；nodeIntegration 关闭；外部导航拦截 |
| 外链 | 只允许 https 的 PetDex zip；`deskpet://` 只处理 install 动作 |
| 数据位置 | 设置与导入皮肤在 `~/Library/Application Support/desktop-pet-mvp/` |
